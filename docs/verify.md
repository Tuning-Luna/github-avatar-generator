# 验证

[简体中文](./verify.md) | [English](./verify.en.md)

使用 Node 20 或更高版本运行无依赖的回归测试：

```sh
node --test tests/*.test.mjs
```

测试覆盖哈希、颜色转换、模板图案（镜像对称在全部 32768 种状态上穷举验证，六个模板逐格可翻转，两种网格模式各自的字节分配逐格验证）、确定性渲染、Unicode 与空种子，以及共享的导出画布尺寸。设置注册表与其 DOM 宿主另有独立测试，无需浏览器。仅浏览器可验证的行为（剪贴板权限、下载、响应式布局，以及关闭「左右对称」后的实际观感）需要在本地 localhost 服务器上手动检查。
