# 工作原理

[简体中文](./how-it-works.md) | [English](./how-it-works.en.md)

1. **输入** -> 裁剪提交的字符串；渲染器在哈希前将其转为小写
2. **哈希** -> 计算 SHA-256
3. **配色** -> 从哈希中提取 HSL 并转换为 RGB
4. **图案** -> 用哈希选出一个模板（噪点、方框、十字、叉、中央方块、棋盘），再按每个格子各自的填充概率决定 5 x 5 网格：左右对称开启时右半镜像左半（15 个自由位，共 32768 种图案），关闭时两半各自填充（25 个自由位）
5. **渲染** -> 在 HTML5 canvas 上以 1000 x 1000 分辨率绘制
6. **导出** -> 下载或复制 PNG，可选与背景同色的边框，每边宽度 0 至 500px（1000 x 1000px 至 2000 x 2000px）

渲染算法位于 `core/`，UI 状态与浏览器操作位于 `ui/`；每一个用户设置是 `ui/features/` 下的一个独立模块，`ui/features/index.js` 是唯一的设置清单；应用不导入也不依赖随附的 `design-system/` 目录。
